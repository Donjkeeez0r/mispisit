# История изменений SalesDrive

## 0.0.6
В форме начисления опыта и в истории сотрудника появился комментарий. Две миграции TypeORM обновляют базу версии 0.0.5 с сохранением записей и присваивают прежним начислениям значение «Без комментария».
Добавлены сервисы Docker Compose для резервного копирования и восстановления PostgreSQL.

## 0.0.5
Добавлены уведомления о начислении опыта и достижении нового уровня. В интерфейсе появился счётчик непрочитанных уведомлений и возможность отметить их прочитанными.

## 0.0.4
Интерфейс переведён на Bootstrap. На главной странице появилась сводка по сотрудникам, начислениям опыта и отклонённым событиям.

## 0.0.3
Данные перенесены из оперативной памяти в PostgreSQL. Приложение работает с базой через TypeORM, а Docker Compose запускает оба сервиса и сохраняет данные в томе dbdata.

## 0.0.2
Добавлены рейтинг отдела, карточка сотрудника с историей начислений, форма регистрации событий CRM и журнал отказов. Данные хранились в памяти приложения.

## 0.0.1
Создана первая страница системы геймификации отдела продаж для Bitrix24 на NestJS и TypeScript. Приложение опубликовано в виде Docker-образа.
