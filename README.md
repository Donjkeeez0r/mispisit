# Система геймификации отдела продаж для Bitrix24. Лабораторная работа №1 по дисциплине МиСПИСИТ.

Стек: Node.js 22, NestJS 10, TypeScript.

## Образ

https://hub.docker.com/r/donjkeeez0r/mispisit-lab1

## Запуск

```bash
docker pull donjkeeez0r/mispisit-lab1:0.0.1
docker run --rm -p 8080:8080 donjkeeez0r/mispisit-lab1:0.0.1
```

После запуска страница доступна по адресу http://localhost:8080
